# Apply the Daydrift design language

Keep the UI cohesive and non-templated. See `docs/05-frontend.md`.

## Rules

- Pull every value from the token set — color scale, type scale, spacing scale. Never ad hoc.
- Apply the **one signature motif** consistently. It is what makes Daydrift not look like a template.

### Do

- Respect the type and spacing rhythm.
- Use semantic token names (not literal colors).
- Keep contrast accessible (WCAG AA).

### Don't

- Introduce new one-off colors.
- Mix competing shadow or radius styles.
- Over-apply animated accents.
