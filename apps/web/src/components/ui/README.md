# components/ui/

**shadcn/ui** component source lives here — owned in-repo and customized freely. This is the foundation for all real product UI (see [docs/05-frontend.md](../../../../../docs/05-frontend.md) §6).

- Style only with Tailwind design tokens — no raw hex/px.
- Reach for Magic UI / Aceternity / React Bits only for intentional **accents** (hero, empty states, the generating moment); default to plain shadcn for everyday UI.
- Use the `daydrift-ui-component` and `daydrift-design-system` skills (see docs/13) when adding or standardizing components.
