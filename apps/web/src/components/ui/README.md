# ui

Owned, customizable primitives in the shadcn/ui style (Radix `Slot`, `class-variance-authority`, `tailwind-merge`). They consume design tokens only: no raw colors.

`button` (variants/sizes, `asChild`), `input`, `card`, `badge`, `skeleton`, and `segmented` (a native-radio single-choice group that keeps keyboard and screen-reader behavior).

Add new primitives here, keep them presentational, and style with semantic token classes (`bg-primary`, `text-muted-foreground`).
